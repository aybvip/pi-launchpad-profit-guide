# Pi Launchpad Profit Guide

> Static website (HTML/CSS/JS) helping Pi Network users understand Launchpad participation and estimate profit/loss.
> **Educational only. Not financial advice. Not affiliated with Pi Network.**

## Live site
https://aybvip.github.io/pi-launchpad-profit-guide/

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
Already configured: Settings → Pages → Source: main branch / root.

## Features
- Interactive profit/loss calculator (Pi amount, tokens, assumed price, sell price, fees, slippage).
- 3 scenarios: optimistic / base / pessimistic + bar chart.
- Bilingual (AR/EN) with RTL.
- Responsive design.
- Official sources with last-updated date.

## Safety
- No 24-word phrase or private keys requested.
- No automatic transactions.
- Estimates only; theoretical price ≠ sellability.
- Testnet vs Mainnet clearly distinguished.
