# Pi Launchpad Profit Guide

Static website (HTML/CSS/JS) helping Pi Network users understand Launchpad participation and estimate profit/loss.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a repo and push these files.
2. Settings → Pages → Source: main branch / root.
3. Site will be published.

## Notes
- Estimates only; not financial advice.
- Launchpad is on Testnet (as of Mar 19, 2026); Mainnet in development.
- No 24-word phrase or private keys requested. No automatic transactions.
- Sources listed in the page (minepi.com, developers.minepi.com, PiRC).
